# Insurance Claims Analysis Dashboard – Power BI

A Power BI practice project focused on analyzing insurance claims, policies, premiums, coverage, and customer data.

## Tools Used
- Power BI
- SQL
- Data Analysis
- Data Visualization

## Dashboard Features
- Premium Amount analysis
- Coverage Amount analysis
- Claim Amount analysis
- Policy Type analysis
- Active vs Inactive policies
- Claim Status analysis
- Age Group analysis
- Gender analysis

## Project Status
This is a learning and practice project created while following a guided Power BI course/tutorial.
